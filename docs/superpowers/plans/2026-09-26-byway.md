# byway Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `byway`, a Go CLI that stores shell commands by name in one TOML registry (captured from shell history or added explicitly) and runs them from fish, zsh or bash.

**Architecture:** One static Go binary. Small internal packages with one job each: `shell` (quoting, init scripts, rc setup), `tmpl` (placeholder resolution), `store` (TOML load/validate and comment-preserving textual edits), `capture` (history picking and parametrisation), `runner` (exec), and `cli` (cobra wiring). Shell integration is a tiny wrapper function, printed by `byway init <shell>`, that exports `BYWAY_INIT` and `BYWAY_LAST_CMD`.

**Tech Stack:** Go (≥ 1.24), `github.com/spf13/cobra`, `github.com/BurntSushi/toml`, test-only `github.com/creack/pty`, goreleaser.

**Spec:** `docs/superpowers/specs/2026-09-26-byway-design.md`

## Global Constraints

- Module path: `github.com/gabrielegenovesi/byway` (if the GitHub handle differs, one `sed` over `go.mod` + imports + `.goreleaser.yaml` + `install.sh`).
- Binary name `byway`; registry `$BYWAY_FILE` → `$XDG_CONFIG_HOME/byway/byway.toml` → `~/.config/byway/byway.toml`.
- Runtime deps: only `spf13/cobra` and `BurntSushi/toml`. `creack/pty` is test-only.
- Target OS: darwin + linux only (uses `syscall.Flock`).
- Placeholders: `{{1}}`, `{{@}}`, `{{name}}`, `{{x:default}}`, `{{env.X}}`, `{{!x}}` raw. Key must start with `[A-Za-z0-9@]`.
- Every non-raw substitution is shell-quoted for the command's shell.
- Registry writes are textual (never re-serialise the whole file), atomic, locked, and refuse to touch an invalid file.
- Env vars: `BYWAY_FILE`, `BYWAY_INIT`, `BYWAY_LAST_CMD`.
- Error output format: `byway: <message>` on stderr, exit 1; a wrapped command's exit code is propagated unchanged.
- Go is not installed on the dev machine yet: `brew install go` before Task 1.

## Review Focus

1. **Registry is a symlink** (dotfiles via stow/chezmoi): writes must update the target and keep the symlink. Covered by the test in Task 4.
2. **Go/docker templates in saved commands** (`docker ps --format '{{.Name}}'`): must stay literal and must not become placeholders. Covered in Tasks 2 and 4.
3. **Captured history includes the `byway save` line itself, blank lines, or leading tabs from `fc`**: pick the real previous command. Covered in Task 5 and by the real-shell run in Task 9.
4. **Wrapper commands receiving `--flag=value` they don't template**: must pass through, not be swallowed as variables. Covered in Task 6.
5. **Non-TTY use (pipes, scripts, CI)**: never prompt, stdin reaches the wrapped command. Covered in Tasks 6, 7 and 8.

// Package shell holds everything that depends on the user's shell:
// quoting, integration scripts and rc-file setup.
package shell

import (
	"regexp"
	"strings"
)

// safe words need no quoting in any supported shell ('=' and '%' excluded:
// zsh expands a leading '=' and fish historically expanded '%').
var safe = regexp.MustCompile(`^[A-Za-z0-9_./:@+,-]+$`)

// Quote returns s as a single literal word for shell sh.
func Quote(s, sh string) string {
	if safe.MatchString(s) {
		return s
	}
	if sh == "fish" {
		r := strings.NewReplacer(`\`, `\\`, `'`, `\'`)
		return "'" + r.Replace(s) + "'"
	}
	return "'" + strings.ReplaceAll(s, "'", `'"'"'`) + "'"
}
```

// Package tmpl resolves {{…}} placeholders in a command template.
package tmpl

import (
	"fmt"
	"os"
	"regexp"
	"strconv"
	"strings"

	"github.com/gabrielegenovesi/byway/internal/shell"
)

// Input is everything a template can draw values from.
type Input struct {
	Args  []string          // positional arguments
	Flags map[string]string // --k=v given on the command line
	Vars  map[string]string // [vars] from the registry
	Env   func(string) (string, bool)
	Shell string // quoting rules; "" means sh
}

// groups: 1 raw marker, 2 key, 3 ":default". Keys start with [A-Za-z0-9@]
// so Go/docker templates like {{.Name}} never match.
var ph = regexp.MustCompile(`\{\{(!?)([A-Za-z0-9@][A-Za-z0-9_.-]*)(:[^{}]*)?\}\}`)

// Resolve substitutes every placeholder in t. Positional args not consumed
// by {{N}} are appended (quoted) unless t contains {{@}}.
func Resolve(t string, in Input) (string, error) {
	if in.Env == nil {
		in.Env = os.LookupEnv
	}
	matches := ph.FindAllStringSubmatchIndex(t, -1)
	maxN, hasAll := 0, false
	for _, m := range matches {
		key := t[m[4]:m[5]]
		if key == "@" {
			hasAll = true
		} else if n, err := strconv.Atoi(key); err == nil && n > maxN {
			maxN = n
		}
	}
	q := func(s string, raw bool) string {
		if raw {
			return s
		}
		return shell.Quote(s, in.Shell)
	}
	rest := []string{}
	if len(in.Args) > maxN {
		rest = in.Args[maxN:]
	}

	var b strings.Builder
	last := 0
	for _, m := range matches {
		b.WriteString(t[last:m[0]])
		last = m[1]
		raw := m[3] > m[2]
		key := t[m[4]:m[5]]
		hasDef := m[6] != -1
		def := ""
		if hasDef {
			def = t[m[6]+1 : m[7]]
		}
		var v string
		switch n, numErr := strconv.Atoi(key); {
		case key == "@":
			parts := make([]string, len(rest))
			for i, a := range rest {
				parts[i] = q(a, raw)
			}
			b.WriteString(strings.Join(parts, " "))
			continue
		case numErr == nil:
			if n < 1 {
				return "", fmt.Errorf("invalid placeholder {{%s}}", key)
			}
			switch {
			case n <= len(in.Args):
				v = in.Args[n-1]
			case hasDef:
				v = def
			default:
				return "", fmt.Errorf("missing argument %d", n)
			}
		case strings.HasPrefix(key, "env."):
			var ok bool
			if v, ok = in.Env(key[4:]); !ok {
				if !hasDef {
					return "", fmt.Errorf("missing environment variable %s", key[4:])
				}
				v = def
			}
		default:
			var ok bool
			if v, ok = in.Flags[key]; !ok {
				if v, ok = in.Vars[key]; !ok {
					if !hasDef {
						return "", fmt.Errorf("missing variable %s (pass --%s=value)", key, key)
					}
					v = def
				}
			}
		}
		b.WriteString(q(v, raw))
	}
	b.WriteString(t[last:])
	if !hasAll {
		for _, a := range rest {
			b.WriteString(" " + q(a, false))
		}
	}
	return b.String(), nil
}

// Refs lists named variables referenced by t, first occurrence order.
func Refs(t string) []string {
	var out []string
	seen := map[string]bool{}
	for _, m := range ph.FindAllStringSubmatch(t, -1) {
		key := m[2]
		if _, err := strconv.Atoi(key); err == nil || key == "@" || strings.HasPrefix(key, "env.") || seen[key] {
			continue
		}
		seen[key] = true
		out = append(out, key)
	}
	return out
}
```

// Package store reads and edits the byway registry file.
package store

import (
	"errors"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
	"regexp"
	"sort"

	"github.com/BurntSushi/toml"
)

type Command struct {
	Run   string   `toml:"run,omitempty"`
	Steps []string `toml:"steps,omitempty"`
	Desc  string   `toml:"desc,omitempty"`
	Shell string   `toml:"shell,omitempty"`
}

type Registry struct {
	Vars map[string]string  `toml:"vars"`
	Cmd  map[string]Command `toml:"cmd"`
}

var nameRe = regexp.MustCompile(`^[a-z0-9_-]+(\.[a-z0-9_-]+)*$`)

func ValidName(n string) bool { return nameRe.MatchString(n) }

// Path returns the registry location: $BYWAY_FILE, then XDG, then ~/.config.
func Path() string {
	if p := os.Getenv("BYWAY_FILE"); p != "" {
		return p
	}
	dir := os.Getenv("XDG_CONFIG_HOME")
	if dir == "" {
		home, _ := os.UserHomeDir()
		dir = filepath.Join(home, ".config")
	}
	return filepath.Join(dir, "byway", "byway.toml")
}

// Load reads path; a missing file is an empty registry.
func Load(path string) (*Registry, error) {
	data, err := os.ReadFile(path)
	if errors.Is(err, fs.ErrNotExist) {
		return Parse(nil)
	}
	if err != nil {
		return nil, err
	}
	return Parse(data)
}

func Parse(data []byte) (*Registry, error) {
	var r Registry
	md, err := toml.Decode(string(data), &r)
	if err != nil {
		return nil, fmt.Errorf("invalid registry: %w (fix it with: byway edit)", err)
	}
	if und := md.Undecoded(); len(und) > 0 {
		return nil, fmt.Errorf("invalid registry: unknown key %q (namespaced names need quotes: [cmd.\"a.b\"])", und[0].String())
	}
	if r.Vars == nil {
		r.Vars = map[string]string{}
	}
	if r.Cmd == nil {
		r.Cmd = map[string]Command{}
	}
	return &r, r.validate()
}

func (r *Registry) Names() []string {
	out := make([]string, 0, len(r.Cmd))
	for n := range r.Cmd {
		out = append(out, n)
	}
	sort.Strings(out)
	return out
}

func (r *Registry) validate() error {
	for _, name := range r.Names() {
		c := r.Cmd[name]
		if !ValidName(name) {
			return fmt.Errorf("command %q: invalid name (use a-z 0-9 _ - and . for namespaces)", name)
		}
		if (c.Run == "") == (len(c.Steps) == 0) {
			return fmt.Errorf("command %q: set exactly one of run or steps", name)
		}
		switch c.Shell {
		case "", "sh", "bash", "zsh", "fish":
		default:
			return fmt.Errorf("command %q: unsupported shell %q", name, c.Shell)
		}
		for _, s := range c.Steps {
			if _, ok := r.Cmd[s]; !ok {
				return fmt.Errorf("command %q: unknown step %q", name, s)
			}
		}
	}
	state := map[string]int{} // 1 visiting, 2 done
	var visit func(string) error
	visit = func(n string) error {
		switch state[n] {
		case 1:
			return fmt.Errorf("command %q: steps form a cycle", n)
		case 2:
			return nil
		}
		state[n] = 1
		for _, s := range r.Cmd[n].Steps {
			if err := visit(s); err != nil {
				return err
			}
		}
		state[n] = 2
		return nil
	}
	for _, n := range r.Names() {
		if err := visit(n); err != nil {
			return err
		}
	}
	return nil
}
```

package store

import (
	"errors"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
	"strings"
	"syscall"
	"time"

	"github.com/BurntSushi/toml"
)

var (
	ErrExists   = errors.New("command already exists (use -f to overwrite)")
	ErrNotFound = errors.New("command not found")
)

// Put adds or (with overwrite) replaces the block for name, editing the file
// as text so user comments and layout survive.
func Put(path, name string, c Command, overwrite bool) error {
	if !ValidName(name) {
		return fmt.Errorf("invalid name %q (use a-z 0-9 _ - and . for namespaces)", name)
	}
	block, err := renderBlock(name, c)
	if err != nil {
		return err
	}
	return edit(path, func(lines []string) ([]string, error) {
		if s, e, ok := findBlock(lines, name); ok {
			if !overwrite {
				return nil, ErrExists
			}
			return splice(lines, s, e, block), nil
		}
		for len(lines) > 0 && strings.TrimSpace(lines[len(lines)-1]) == "" {
			lines = lines[:len(lines)-1]
		}
		if len(lines) > 0 {
			lines = append(lines, "")
		}
		return append(lines, block...), nil
	})
}

func Remove(path, name string) error {
	return edit(path, func(lines []string) ([]string, error) {
		s, e, ok := findBlock(lines, name)
		if !ok {
			return nil, ErrNotFound
		}
		lines = splice(lines, s, e, nil)
		if s > 0 && s < len(lines) && strings.TrimSpace(lines[s-1]) == "" && strings.TrimSpace(lines[s]) == "" {
			lines = append(lines[:s], lines[s+1:]...)
		}
		return lines, nil
	})
}

// Line returns the 1-based line of name's [cmd.…] header.
func Line(path, name string) (int, error) {
	lines, err := readLines(resolve(path))
	if err != nil {
		return 0, err
	}
	s, _, ok := findBlock(lines, name)
	if !ok {
		return 0, ErrNotFound
	}
	return s + 1, nil
}

// edit runs fn on the file's lines under lock; the result must still parse.
func edit(path string, fn func([]string) ([]string, error)) error {
	path = resolve(path)
	return withLock(filepath.Dir(path), func() error {
		lines, err := readLines(path)
		if err != nil {
			return err
		}
		if _, err := Parse([]byte(strings.Join(lines, "\n"))); err != nil {
			return err
		}
		if lines, err = fn(lines); err != nil {
			return err
		}
		for len(lines) > 0 && strings.TrimSpace(lines[len(lines)-1]) == "" {
			lines = lines[:len(lines)-1]
		}
		data := strings.Join(lines, "\n") + "\n"
		if _, err := Parse([]byte(data)); err != nil {
			return fmt.Errorf("refusing to write: %w", err)
		}
		return writeAtomic(path, []byte(data))
	})
}

// resolve follows a symlinked registry (dotfiles) so writes hit the target.
func resolve(path string) string {
	if p, err := filepath.EvalSymlinks(path); err == nil {
		return p
	}
	return path
}

func readLines(path string) ([]string, error) {
	data, err := os.ReadFile(path)
	if errors.Is(err, fs.ErrNotExist) || len(data) == 0 {
		return nil, nil
	}
	if err != nil {
		return nil, err
	}
	return strings.Split(strings.TrimRight(string(data), "\n"), "\n"), nil
}

func renderBlock(name string, c Command) ([]string, error) {
	hdr := "[cmd." + name + "]"
	if strings.Contains(name, ".") {
		hdr = `[cmd."` + name + `"]`
	}
	body, err := toml.Marshal(c)
	if err != nil {
		return nil, err
	}
	return append([]string{hdr}, strings.Split(strings.TrimRight(string(body), "\n"), "\n")...), nil
}

// header returns the table name of a "[…]" line with spaces removed.
func header(l string) (string, bool) {
	t := strings.TrimSpace(l)
	if !strings.HasPrefix(t, "[") {
		return "", false
	}
	i := strings.Index(t, "]")
	if i < 0 {
		return "", false
	}
	return strings.ReplaceAll(strings.Trim(t[:i], "["), " ", ""), true
}

// findBlock returns [start,end) of name's block. Trailing blank and comment
// lines belong to the next block, not this one.
// ponytail: line-based; a multi-line string whose line starts with "[" would confuse it.
func findBlock(lines []string, name string) (int, int, bool) {
	start, end := -1, len(lines)
	for i, l := range lines {
		h, ok := header(l)
		if !ok {
			continue
		}
		if start >= 0 {
			end = i
			break
		}
		if h == "cmd."+name || h == `cmd."`+name+`"` || h == "cmd.'"+name+"'" {
			start = i
		}
	}
	if start < 0 {
		return 0, 0, false
	}
	for end-1 > start {
		t := strings.TrimSpace(lines[end-1])
		if t != "" && !strings.HasPrefix(t, "#") {
			break
		}
		end--
	}
	return start, end, true
}

func splice(lines []string, s, e int, repl []string) []string {
	out := append([]string{}, lines[:s]...)
	out = append(out, repl...)
	return append(out, lines[e:]...)
}

// withLock takes an exclusive flock on the registry directory (no stray lock file).
func withLock(dir string, fn func() error) error {
	if err := os.MkdirAll(dir, 0o755); err != nil {
		return err
	}
	f, err := os.Open(dir)
	if err != nil {
		return err
	}
	defer f.Close()
	deadline := time.Now().Add(2 * time.Second)
	for syscall.Flock(int(f.Fd()), syscall.LOCK_EX|syscall.LOCK_NB) != nil {
		if time.Now().After(deadline) {
			return fmt.Errorf("registry is locked by another byway process (%s)", dir)
		}
		time.Sleep(50 * time.Millisecond)
	}
	defer syscall.Flock(int(f.Fd()), syscall.LOCK_UN)
	return fn()
}

func writeAtomic(path string, data []byte) error {
	mode := fs.FileMode(0o644)
	if st, err := os.Stat(path); err == nil {
		mode = st.Mode().Perm()
	}
	tmp, err := os.CreateTemp(filepath.Dir(path), ".byway-*.toml")
	if err != nil {
		return err
	}
	defer os.Remove(tmp.Name()) // no-op after a successful rename
	if _, err := tmp.Write(data); err != nil {
		tmp.Close()
		return err
	}
	if err := tmp.Chmod(mode); err != nil {
		tmp.Close()
		return err
	}
	if err := tmp.Close(); err != nil {
		return err
	}
	return os.Rename(tmp.Name(), path)
}

// Package capture turns a shell-history entry into a saved command.
package capture

import (
	"errors"
	"fmt"
	"regexp"
	"strings"
)

var selfRe = regexp.MustCompile(`^(command\s+)?byway\s+save(\s|$)`)

// PickLast returns the newest entry in raw (oldest first) that is not the
// "byway save" call itself.
// ponytail: multi-line history entries arrive split; the last line wins.
func PickLast(raw string) (string, error) {
	lines := strings.Split(raw, "\n")
	for i := len(lines) - 1; i >= 0; i-- {
		l := strings.TrimSpace(lines[i])
		if l != "" && !selfRe.MatchString(l) {
			return l, nil
		}
	}
	return "", errors.New("no previous command found in shell history")
}

var keyRe = regexp.MustCompile(`^([1-9][0-9]*|[a-z0-9_-]+)$`)

// Parametrize replaces whole-word occurrences of each value with {{KEY}}.
func Parametrize(cmd string, subs []string) (string, error) {
	for _, s := range subs {
		k, v, ok := strings.Cut(s, "=")
		if !ok || v == "" || !keyRe.MatchString(k) || k == "0" {
			return "", fmt.Errorf("--arg %q: want N=value or name=value", s)
		}
		qv := regexp.QuoteMeta(v)
		re := regexp.MustCompile(`(^|[\s=/:,('"])(?:"` + qv + `"|'` + qv + `'|` + qv + `)($|[\s/:,;&|).'"])`)
		if !re.MatchString(cmd) {
			return "", fmt.Errorf("--arg %s: %q not found as a whole word in: %s", k, v, cmd)
		}
		// repeat: adjacent matches share a boundary char and need a second pass
		for {
			next := re.ReplaceAllString(cmd, "${1}{{"+k+"}}${2}")
			if next == cmd {
				break
			}
			cmd = next
		}
	}
	return cmd, nil
}

// Package runner executes resolved command lines.
package runner

import (
	"errors"
	"io"
	"os/exec"
)

type Step struct {
	Shell string // "" means sh
	Line  string
}

// Run executes steps in order, inheriting stdio, and returns the first
// non-zero exit code.
func Run(steps []Step, in io.Reader, out, errw io.Writer) (int, error) {
	for _, s := range steps {
		bin := s.Shell
		if bin == "" {
			bin = "sh"
		}
		c := exec.Command(bin, "-c", s.Line)
		c.Stdin, c.Stdout, c.Stderr = in, out, errw
		err := c.Run()
		var ee *exec.ExitError
		switch {
		case errors.As(err, &ee):
			return ee.ExitCode(), nil
		case err != nil:
			return 127, err
		}
	}
	return 0, nil
}

// run resolves args to a command and executes (or prints) it.
func (a *app) run(cmd *cobra.Command, args []string) error {
	reg, err := a.load()
	if err != nil {
		return err
	}
	name, rest, err := resolveName(reg, args)
	if err != nil {
		return err
	}
	known := map[string]bool{}
	refs(reg, name, known)
	flags, pos := splitArgs(rest, known)
	steps, err := plan(reg, name, pos, flags)
	if err != nil {
		return fmt.Errorf("%s: %w", name, err)
	}
	if a.dryRun {
		for _, s := range steps {
			fmt.Fprintln(cmd.OutOrStdout(), s.Line)
		}
		return nil
	}
	code, err := runner.Run(steps, cmd.InOrStdin(), cmd.OutOrStdout(), cmd.ErrOrStderr())
	if err != nil {
		return err
	}
	if code != 0 {
		return exitError(code)
	}
	return nil
}

// resolveName finds the longest prefix of args that, joined by ".", names a command.
func resolveName(reg *store.Registry, args []string) (string, []string, error) {
	for i := len(args); i >= 1; i-- {
		n := strings.Join(args[:i], ".")
		if _, ok := reg.Cmd[n]; ok {
			return n, args[i:], nil
		}
	}
	return "", nil, notFound(reg, args[0])
}

func notFound(reg *store.Registry, typed string) error {
	var near []string
	for _, n := range reg.Names() {
		if levenshtein(typed, n) <= 2 {
			near = append(near, n)
		}
	}
	if len(near) > 0 {
		return fmt.Errorf("%q not found. Did you mean: %s?", typed, strings.Join(near, ", "))
	}
	return fmt.Errorf("%q not found (see: byway ls)", typed)
}

func levenshtein(a, b string) int {
	ra, rb := []rune(a), []rune(b)
	prev := make([]int, len(rb)+1)
	for j := range prev {
		prev[j] = j
	}
	for i := 1; i <= len(ra); i++ {
		cur := make([]int, len(rb)+1)
		cur[0] = i
		for j := 1; j <= len(rb); j++ {
			cost := 1
			if ra[i-1] == rb[j-1] {
				cost = 0
			}
			cur[j] = min(prev[j]+1, cur[j-1]+1, prev[j-1]+cost)
		}
		prev = cur
	}
	return prev[len(rb)]
}

func refs(reg *store.Registry, name string, into map[string]bool) {
	c := reg.Cmd[name]
	for _, k := range tmpl.Refs(c.Run) {
		into[k] = true
	}
	for _, s := range c.Steps {
		refs(reg, s, into)
	}
}

var flagRe = regexp.MustCompile(`^--([A-Za-z0-9_-]+)=(.*)$`)

// splitArgs pulls --k=v for referenced k (before "--"); the rest is positional.
func splitArgs(rest []string, known map[string]bool) (map[string]string, []string) {
	flags := map[string]string{}
	var pos []string
	for i, arg := range rest {
		if arg == "--" {
			return flags, append(pos, rest[i+1:]...)
		}
		if m := flagRe.FindStringSubmatch(arg); m != nil && known[m[1]] {
			flags[m[1]] = m[2]
			continue
		}
		pos = append(pos, arg)
	}
	return flags, pos
}

func plan(reg *store.Registry, name string, pos []string, flags map[string]string) ([]runner.Step, error) {
	c := reg.Cmd[name]
	if c.Run != "" {
		line, err := tmpl.Resolve(c.Run, tmpl.Input{Args: pos, Flags: flags, Vars: reg.Vars, Shell: c.Shell})
		if err != nil {
			return nil, err
		}
		return []runner.Step{{Shell: c.Shell, Line: line}}, nil
	}
	if len(pos) > 0 {
		return nil, errors.New("takes no arguments (it runs steps)")
	}
	var out []runner.Step
	for _, s := range c.Steps {
		sub, err := plan(reg, s, nil, flags)
		if err != nil {
			return nil, fmt.Errorf("step %s: %w", s, err)
		}
		out = append(out, sub...)
	}
	return out, nil
}

// eatGlobal parses -n/--dry-run/--file for subcommands that disable flag parsing.
func (a *app) eatGlobal(args []string) []string {
	for len(args) > 0 {
		switch {
		case args[0] == "-n" || args[0] == "--dry-run":
			a.dryRun = true
		case args[0] == "--file" && len(args) > 1:
			a.file = args[1]
			args = args[1:]
		case strings.HasPrefix(args[0], "--file="):
			a.file = strings.TrimPrefix(args[0], "--file=")
		default:
			return args
		}
		args = args[1:]
	}
	return args
}

func reserved(root *cobra.Command, name string) bool {
	first, _, _ := strings.Cut(name, ".")
	if first == "help" {
		return true
	}
	for _, c := range root.Commands() {
		if c.Name() == first {
			return true
		}
	}
	return false
}

func (a *app) put(cmd *cobra.Command, name string, c store.Command, force bool) error {
	if reserved(cmd.Root(), name) {

package shell

import (
	"errors"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
	"strings"
)

const marker = "# byway"

// brew installs this for fish; its presence counts as installed.
var fishVendor = []string{
	"/opt/homebrew/share/fish/vendor_conf.d/byway.fish",
	"/usr/local/share/fish/vendor_conf.d/byway.fish",
	"/home/linuxbrew/.linuxbrew/share/fish/vendor_conf.d/byway.fish",
}

func DetectShell(shellEnv string) string {
	switch b := filepath.Base(shellEnv); b {
	case "fish", "zsh", "bash":
		return b
	}
	return ""
}

// ponytail: bash uses ~/.bashrc only; macOS login bash reads ~/.bash_profile, add when someone asks.
func RCPath(sh, home string) (string, error) {
	switch sh {
	case "zsh":
		return filepath.Join(home, ".zshrc"), nil
	case "bash":
		return filepath.Join(home, ".bashrc"), nil
	case "fish":
		return filepath.Join(home, ".config", "fish", "conf.d", "byway.fish"), nil
	}
	return "", fmt.Errorf("unsupported shell %q (supported: fish, zsh, bash)", sh)
}

func Setup(sh, home string) (string, error) {
	p, err := RCPath(sh, home)
	if err != nil {
		return "", err
	}
	if sh == "fish" {
		if err := os.MkdirAll(filepath.Dir(p), 0o755); err != nil {
			return "", err
		}
		return p, os.WriteFile(p, []byte("command byway init fish | source\n"), 0o644)
	}
	data, err := os.ReadFile(p)
	if err != nil && !errors.Is(err, fs.ErrNotExist) {
		return "", err
	}
	if hasMarker(string(data)) {
		return p, nil
	}
	line := fmt.Sprintf("eval \"$(command byway init %s)\"  %s\n", sh, marker)
	if len(data) > 0 && !strings.HasSuffix(string(data), "\n") {
		line = "\n" + line
	}
	f, err := os.OpenFile(p, os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0o644)
	if err != nil {
		return "", err
	}
	defer f.Close()
	_, err = f.WriteString(line)
	return p, err
}

func Uninstall(sh, home string) (string, error) {
	p, err := RCPath(sh, home)
	if err != nil {
		return "", err
	}
	if sh == "fish" {
		if err := os.Remove(p); err != nil && !errors.Is(err, fs.ErrNotExist) {
			return "", err
		}
		return p, nil
	}
	data, err := os.ReadFile(p)
	if errors.Is(err, fs.ErrNotExist) {
		return p, nil
	}
	if err != nil {
		return "", err
	}
	var keep []string
	for _, l := range strings.SplitAfter(string(data), "\n") {
		if !isMarkerLine(l) {
			keep = append(keep, l)
		}
	}
	return p, os.WriteFile(p, []byte(strings.Join(keep, "")), 0o644)
}

func Installed(sh, home string) bool {
	p, err := RCPath(sh, home)
	if err != nil {
		return false
	}
	if sh == "fish" {
		for _, c := range append([]string{p}, fishVendor...) {
			if _, err := os.Stat(c); err == nil {
				return true
			}
		}
		return false
	}
	data, _ := os.ReadFile(p)
	return hasMarker(string(data))
}

func isMarkerLine(l string) bool {
	t := strings.TrimSpace(l)
	return strings.HasSuffix(t, marker) && strings.Contains(t, "byway init")
}

func hasMarker(s string) bool {
	for _, l := range strings.Split(s, "\n") {
		if isMarkerLine(l) {
			return true
		}
	}
	return false
}

func declinedPath() string {
	dir := os.Getenv("XDG_STATE_HOME")
	if dir == "" {
		home, _ := os.UserHomeDir()
		dir = filepath.Join(home, ".local", "state")
	}
	return filepath.Join(dir, "byway", "declined")
}

func Declined() bool {
	_, err := os.Stat(declinedPath())
	return err == nil
}

func Decline() error {
	p := declinedPath()
	if err := os.MkdirAll(filepath.Dir(p), 0o755); err != nil {
		return err
	}
	return os.WriteFile(p, nil, 0o644)
}

package cli

import (
	"bufio"
	"fmt"
	"os"
	"strings"

	"github.com/spf13/cobra"

	"github.com/gabrielegenovesi/byway/internal/shell"
)

func (a *app) addSetup(root *cobra.Command) {
	root.AddCommand(initCmd(), setupCmd())
	root.PersistentPreRun = func(cmd *cobra.Command, args []string) {
		home, err := os.UserHomeDir()
		if err != nil {
			return
		}
		tty := isTTY(cmd.InOrStdin()) && isTTY(cmd.OutOrStdout())
		sh, ok := offerNeeded(cmd.Name(), os.Getenv, home, tty)
		if !ok {
			return
		}
		rc, _ := shell.RCPath(sh, home)
		fmt.Fprintf(cmd.ErrOrStderr(), "Add byway integration to %s? [Y/n] ", rc)
		ans, _ := bufio.NewReader(cmd.InOrStdin()).ReadString('\n')
		switch strings.ToLower(strings.TrimSpace(ans)) {
		case "", "y", "yes":
			if _, err := shell.Setup(sh, home); err != nil {
				fmt.Fprintln(cmd.ErrOrStderr(), "byway: setup failed:", err)
				return
			}
			fmt.Fprintln(cmd.ErrOrStderr(), "done: open a new shell to enable `byway save` and completions")
		default:
			_ = shell.Decline()
		}
	}
}

// offerNeeded decides whether to ask once to install the shell integration.
func offerNeeded(cmdName string, getenv func(string) string, home string, tty bool) (string, bool) {
	switch cmdName {
	case "init", "setup", "__names", "help":
		return "", false
	}
	if !tty || getenv("BYWAY_INIT") != "" {
		return "", false
	}
	sh := shell.DetectShell(getenv("SHELL"))
	if sh == "" || shell.Installed(sh, home) || shell.Declined() {
		return "", false
	}
	return sh, true
}

func initCmd() *cobra.Command {
	return &cobra.Command{
		Use: "init <fish|zsh|bash>", Short: "Print the shell integration script", Args: cobra.ExactArgs(1),
		RunE: func(cmd *cobra.Command, args []string) error {
			s, err := shell.InitScript(args[0])
			if err != nil {
				return err
			}
			fmt.Fprint(cmd.OutOrStdout(), s)
			return nil
		},
	}
}

func setupCmd() *cobra.Command {
	var sh string
	var uninstall bool
	c := &cobra.Command{
		Use: "setup", Short: "Install (or remove) the shell integration", Args: cobra.NoArgs,
		RunE: func(cmd *cobra.Command, args []string) error {
			if sh == "" {
				sh = shell.DetectShell(os.Getenv("SHELL"))
			}
			if sh == "" {
				return fmt.Errorf("cannot detect shell from $SHELL=%q; pass --shell fish|zsh|bash", os.Getenv("SHELL"))
			}
			home, err := os.UserHomeDir()
			if err != nil {
				return err
			}
			if uninstall {
				p, err := shell.Uninstall(sh, home)
				if err == nil {
					fmt.Fprintf(cmd.OutOrStdout(), "removed byway integration from %s\n", p)
				}
				return err
			}
			p, err := shell.Setup(sh, home)
			if err == nil {
				fmt.Fprintf(cmd.OutOrStdout(), "byway integration added to %s: open a new shell\n", p)
			}
			return err
		},
	}
	c.Flags().StringVar(&sh, "shell", "", "fish, zsh or bash (default: from $SHELL)")
	c.Flags().BoolVar(&uninstall, "uninstall", false, "remove the integration")
	return c
}

package integration

import (
	"bytes"
	"io"
	"os"
	"os/exec"
	"path/filepath"
	"sync"
	"testing"
	"time"

	"github.com/creack/pty"

	"github.com/gabrielegenovesi/byway/internal/store"
)

type syncBuf struct {
	mu sync.Mutex
	b  bytes.Buffer
}

func (s *syncBuf) Write(p []byte) (int, error) { s.mu.Lock(); defer s.mu.Unlock(); return s.b.Write(p) }
func (s *syncBuf) String() string              { s.mu.Lock(); defer s.mu.Unlock(); return s.b.String() }

func buildBinary(t *testing.T) string {
	t.Helper()
	dir := t.TempDir()
	c := exec.Command("go", "build", "-o", filepath.Join(dir, "byway"), "../cmd/byway")
	c.Stderr = os.Stderr
	if err := c.Run(); err != nil {
		t.Fatal(err)
	}
	return dir
}

func must(t *testing.T, err error) {
	t.Helper()
	if err != nil {
		t.Fatal(err)
	}
}

// shellCmd returns an interactive shell whose startup loads byway's integration.
func shellCmd(t *testing.T, sh, home string) *exec.Cmd {
	switch sh {
	case "bash":
		rc := filepath.Join(home, ".bashrc")
		must(t, os.WriteFile(rc, []byte(`eval "$(command byway init bash)"`+"\n"), 0o644))
		return exec.Command("bash", "--noprofile", "--rcfile", rc, "-i")
	case "zsh":
		must(t, os.WriteFile(filepath.Join(home, ".zshrc"), []byte(`eval "$(command byway init zsh)"`+"\n"), 0o644))
		return exec.Command("zsh", "-i")
	default: // fish
		dir := filepath.Join(home, ".config", "fish")
		must(t, os.MkdirAll(dir, 0o755))
		must(t, os.WriteFile(filepath.Join(dir, "config.fish"), []byte("command byway init fish | source\n"), 0o644))
		return exec.Command("fish", "-i")
	}
}

func TestSaveFromRealShells(t *testing.T) {
	bindir := buildBinary(t)
	for _, sh := range []string{"bash", "zsh", "fish"} {
		t.Run(sh, func(t *testing.T) {
			if _, err := exec.LookPath(sh); err != nil {
				t.Skipf("%s not installed", sh)
			}
			home := t.TempDir()
			reg := filepath.Join(home, "byway.toml")
			env := append(os.Environ(),
				"HOME="+home, "ZDOTDIR="+home, "BYWAY_FILE="+reg, "TERM=dumb",
				"PATH="+bindir+string(os.PathListSeparator)+os.Getenv("PATH"),
				"XDG_CONFIG_HOME="+filepath.Join(home, ".config"),
				"XDG_DATA_HOME="+filepath.Join(home, ".local", "share"),
				"XDG_STATE_HOME="+filepath.Join(home, ".local", "state"),
				"HISTFILE="+filepath.Join(home, ".hist"))
			c := shellCmd(t, sh, home)
			c.Env = env
			f, err := pty.Start(c)
			must(t, err)
			defer f.Close()
			var buf syncBuf
			go io.Copy(&buf, f)

			for _, line := range []string{"echo hello-byway", "byway save hi", "exit"} {
				time.Sleep(time.Second) // let the shell draw its prompt
				f.Write([]byte(line + "\r"))
			}
			done := make(chan error, 1)
			go func() { done <- c.Wait() }()
			select {
			case <-done:
			case <-time.After(20 * time.Second):
				c.Process.Kill()
				t.Fatalf("%s hung; session:\n%s", sh, buf.String())
			}

			r, err := store.Load(reg)
			if err != nil || r.Cmd["hi"].Run != "echo hello-byway" {
				t.Fatalf("saved %q (err %v); session:\n%s", r.Cmd["hi"].Run, err, buf.String())
			}
			run := exec.Command(filepath.Join(bindir, "byway"), "hi")
			run.Env = env
			if out, err := run.Output(); err != nil || string(out) != "hello-byway\n" {
				t.Fatalf("byway hi = %q, %v", out, err)
			}
		})
	}
}

curl -fsSL "https://github.com/$REPO/releases/download/v$ver/byway_${ver}_${os}_${arch}.tar.gz" | tar -xz -C "$tmp"
mkdir -p "$dir"
install -m 0755 "$tmp/byway" "$dir/byway"
echo "installed byway $ver to $dir/byway"
case ":$PATH:" in *":$dir:"*) ;; *) echo "note: add $dir to your PATH" ;; esac
"$dir/byway" setup || true
```

````markdown
# byway

Save any shell command by name, run it from anywhere. One registry for fish, zsh and bash. No more scattered git aliases, `~/Makefile` targets and shell functions.

```sh
docker start postgres
byway save pg               # saves the command you just ran
byway pg                    # runs it

git checkout -b feat-x
byway save new --arg 1=feat-x   # -> git checkout -b {{1}}
byway new feat-y
```

## Install

```sh
brew install gabrielegenovesi/byway/byway   # fish: ready. zsh/bash: answer Y on first run
# or
curl -fsSL https://raw.githubusercontent.com/gabrielegenovesi/byway/main/install.sh | sh
```

## Registry

`~/.config/byway/byway.toml` (or `$BYWAY_FILE`). Edit it by hand anytime (`byway edit [name]`); byway keeps your comments.

```toml
[vars]
db = "postgres"

[cmd."docker.pg"]                 # byway docker pg
run  = "docker start {{db}}"
desc = "start postgres"

[cmd."docker.up"]
steps = ["docker.pg", "docker.redis"]
```

Placeholders: `{{1}}` `{{@}}` `{{name}}` `{{1:default}}` `{{env.HOME}}`; `{{!x}}` inserts raw (unquoted). Values are shell-quoted. `{{.Go}}`-style templates are left alone.

## Commands

`byway <name> [args]` · `save` · `add <name> -- cmd` · `ls [ns]` · `show` · `rm` · `edit` · `setup [--uninstall]` · `init <shell>` · `-n` dry-run
````
